# Pixels CTF — Writeups
 
Writeups from our team's run through **Pixels CTF**, covering the challenges we solved across Crypto, Forensics, Reverse Engineering, and Web.
 
Each writeup describes the actual approach we took to solve the challenge — tools used, dead ends, and the reasoning that got us to the flag. Source code and challenge files aren't included in this repo; writeups describe behavior and vulnerabilities in our own words instead.

## Tools we used
 
- **CyberChef** — encoding/cipher identification and brute forcing (XOR Brute Force, Magic)
- **Wireshark** — packet capture analysis, Follow TCP Stream
- **fcrackzip** — zip password cracking against wordlists
- **rockyou.txt** — common-password wordlist for cracking
- **linuxCLI**
